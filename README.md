# Matrix macOS Screen Saver

A native macOS `.saver` bundle with animated green digital rain, a deep black-green backdrop, and softly glowing lead glyphs.

## Build

Open `MatrixScreenSaver.xcodeproj` in Xcode and build the **Matrix** target. The product is written to `build/Debug/Matrix.saver` (or `build/Release/Matrix.saver` for a Release build).

To install for the current user, copy `Matrix.saver` from Xcode's Products folder to `~/Library/Screen Savers/`, then select **Matrix** in System Settings → Screen Saver.
